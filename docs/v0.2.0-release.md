# What's new in release 0.2.0

The 0.2.0 release includes many performance improvements, hence, we are refactoring the logic of the project. Here are the improvements that are added to the project:

1. Reducing the chain validation executions. Before 0.2.0, when adding a block the chain validation validates the whole chain to check if the block is safe to insert, and also when mining the new block, which creates a redundant code execution.

2. Adding an in-memory index for lookups. Before 0.2.0, finding a user, credential or an authority causes the program to scan the full chain just to find a specific info in a block.

3. Adding a new validation class `InputValidation`. Checks the validity of the data received from the API before adding it to the chain. This ensures the quality of the data and adds a security layer to the system.
